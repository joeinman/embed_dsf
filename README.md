# EmbedDSF

![GitHub Release](https://img.shields.io/github/v/release/joeinman/embed_dsf?sort=semver)
![CMake Build](https://github.com/joeinman/embed_dsf/actions/workflows/build.yml/badge.svg)
![Clang-Format Lint](https://github.com/joeinman/embed_dsf/actions/workflows/clang.yml/badge.svg)

A lightweight Data Serialization Format library for JSON and YAML. EmbedDSF offers a shared `Node` type and error surface so applications can parse or emit JSON *and* YAML documents with identical data structures.
